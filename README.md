# aback-hq/.github

Aback Group's organization profile and default community health files.

- `profile/README.md` is the public overview shown on [github.com/aback-hq](https://github.com/aback-hq).
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, and the issue and pull request templates in `.github/` apply to every public repository in the organization that doesn't have its own.

Update the product list in `profile/README.md` when a product is announced on [aback.group](https://aback.group).
