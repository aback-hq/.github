# Contributing

Thanks for your interest in improving an Aback project.

1. **Check the repository first.** Many repositories have their own `CONTRIBUTING.md`, `AGENTS.md` (product and engineering rules) and `DESIGN.md` (design system). Those take precedence over this file.
2. **Open an issue before large changes.** For anything beyond a small fix, describe the problem and your proposed change first, so we can agree on the approach before you spend time on it.
3. **Keep pull requests focused.** One change per pull request, with a clear description of what changed and why, and how you tested it.
4. **Run the checks.** Most projects use [Bun](https://bun.sh): run `bun run lint`, `bun run typecheck` and `bun run test` before opening a pull request.
5. **Be respectful.** Everyone taking part is expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Security issues should not be reported in public issues. See [SECURITY.md](SECURITY.md).
